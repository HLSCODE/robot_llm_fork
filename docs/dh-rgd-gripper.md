# 大寰 RGD 旋转夹爪

原始资料：[RGD 手册 V2.1](references/RGD-系列操作手册_V2.1.pdf)、[测试 Demo](../examples/hardware/rgd_gripper_control.py)。Demo 不属于生产驱动，运行前注意默认端口和自动初始化行为。

通过 `provider = "dh_rgd"` 接入现有末端设备体系，与机械臂品牌无关，可固定安装在左/右臂，也可配置为快换工具。串口由共享连接池管理，不单独打开第二个串口。

## 配置

1. 将 `config/fragments/end-effectors/dh-rgd.example.toml` 复制为同目录 `dh-rgd.toml`（配置初始化命令也会增量生成）。
2. 在 `config/config.toml` 的 `include` 中加入 `"fragments/end-effectors/dh-rgd.toml"`。
3. 在 `connections.toml` 中声明实际连接，并将工具的 `connection` 指向它。出厂通信参数为 115200、8N1，默认站号 1；端口必须按现场填写。不同物理串口使用不同连接 ID。
4. 在 `end-effectors.toml` 中选择挂载，例如：

```toml
[end_effectors.mounts.left]
mode = "fixed"
tool = "dh_rgd_gripper_1"
```

替换已有的对应挂载表，不要重复声明。如果是快换安装，则保留 `mode = "exchangeable"`、`changer`，把工具 ID 加入 `tools`，并确保夹爪与快换手引用同一连接。工具 ID 不表示左右臂。

| 配置 | 含义 |
| --- | --- |
| `station` | Modbus 地址，1～247 |
| `speed` / `torque` | 开合速度 1～100% / 开合力 20～100% |
| `rotation_speed` / `rotation_force` | 旋转速度 1～100% / 力 20～100% |
| `rotation_units_per_degree` | 每度对应的寄存器单位；V2.1 手册为 1，Demo 所述新固件为 10 |
| `open_position` / `closed_position` | 原始开合位置端点，0～1000且不能相同；默认沿用 Demo 的0开、1000关，现场核对后可反向配置 |
| `response_timeout_seconds` | 单次通信超时 |
| `motion_timeout_seconds` | 每次动作等待期限 |
| `command_interval_seconds` | 状态轮询间隔 |

**必须先确认实际固件的角度单位，再执行旋转。** 不自动读取未在 V2.1 手册列出的 `0x050B`，也不在读取失败时猜测比例。旋转指令按有符号16位补码编码（手册负数示例 `-360 → FE98`），超范围拒绝，不静默截断。

## 使用

可在工具表中填写 `display_name = "大寰旋转夹爪"`；别名只用于显示，动作仍保存实例 ID。手动面板和基础动作表单依据 Provider 已声明能力显示操作，不通过连接硬件来发现能力。

末端手动控制面板现支持张开、夹持、开度定位、主动初始化，以及相对/绝对旋转角度输入和停止旋转。执行时普通控件置灰，停止按钮保持可用；对正在运行的同一工具手动旋转，会取消当前动作，由驱动在轮询检查点发送停止指令，不排队重复提交动作。其他正在运行的工作流仍应使用主界面的任务停止控制。

在基础动作的执行类中选择“夹爪”，指定机械臂、工具实例：

- `初始化`：发送 `0x0100=1` 并等待开合与旋转初始化状态均为成功。初始化可能产生运动，须在安全环境主动执行。
- `开`、`关`、`定位`：使用配置的力/速度；定位参数“闭合度”始终为0全开、100全闭。
- `绝对旋转`、`相对旋转`：填写“旋转角度”（度）。绝对角度是累计角度，不是单圈角度；相对角度以当前位置为参考。累计超出16位范围会拒绝。
- `停止旋转`：发送 `0x0502=1`，是减速停止命令，**不是急停，也不能停止开合轴**。固件须支持该命令（手册注明1.14以后）。

动作表单仅在定位时显示闭合度，旋转时显示角度；知行等非旋转夹爪不提供旋转选项。已有动作若保存了当前工具不支持的操作，会保留提示并要求重新选择，不静默改写；其他 Provider 不支持的新操作在执行层仍会明确报错，不会尝试发送 RGD 指令。

## 失败与生命周期

- 构造和程序启动不发送初始化、位置、旋转或 Flash 保存命令；未连接不阻止界面启动，在实际操作时报告通信失败。
- 关闭程序只释放借用连接，不自动松开夹爪，不执行重新标定。
- 接触夹持允许闭合提前结束；张开受阻、物体掉落、报警、旋转堵转均按失败处理，不沿用 Demo 将状态2/3都视为成功的行为。
- 同时核对完成状态和目标反馈，避免上一次“到位”状态直接完成新动作。旋转超时、取消或失败会尽力发送停止，停止失败保留原始异常并记录日志。
- 相对旋转等写命令不自动重试，避免应答丢失导致重复旋转。串口读写受单次通信超时约束；取消在轮询检查点生效，不能替代实体急停。
- 本次未开放全行程重新标定、修改站号/波特率、写 Flash、物理旋转回零等维护指令，避免普通流程误触发。

验证采用模拟 Provider 与伪 Modbus 总线，不连接真实硬件。首次实机验收先清空工作区域，以低力/低速度核对开闭方向、初始化行为和小角度正反旋转，再逐步启用正式工作流。
