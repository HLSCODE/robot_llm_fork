# 机械臂示教

左侧导航的“示教”打开独立工作区，返回任务或基础动作时保留流程编辑内容。
右侧三维区域目前仅为占位，不加载模型、不启用三维渲染或物理仿真。

## 使用

1. 通过设备菜单初始化机械臂。示教页面不会隐式连接设备或自动移动。
2. 选择左臂/右臂，点击“进入示教”，等待读取实际状态。
3. 选择笛卡尔或关节单步移动，设置步长、速度后点击对应轴的 `−` / `+`。
4. 每次点击只执行一个阻塞单步，不自动重复、不排队；完成后才能再移动。
5. 点击“保存当前位置为动作”，输入名称，采集当前位置并保存到当前 Robot Profile 的基础动作库。
6. 点击“停止 / 退出示教”释放控制权，再切换机械臂；切换页面、应用失去焦点或关闭窗口也会请求停止。

单步执行期间方向箭头和保存按钮置灰，完成后恢复；停止按钮保持可用。
运动类型、步长和速度的修改仅影响下一次提交，不会改变正在执行的指令。
未进入示教、已停止或状态数据过期时，控制区仍会禁用。

笛卡尔位姿保存为 `move_l` 动作，不使用视觉补偿。关节目标保存为 `move_joints`，
目前已有动作 schema 仅支持七关节目标；其他关节数不开放关节动作保存。
RealMan 当前适配器未暴露 `ArmJointMotion` 时禁用关节移动，仍显示实际关节角。

## 坐标与限制

- 天机使用 SDK 位姿的世界参考系，RealMan 使用机械臂基座参考系；当前不提供工具坐标系切换。
- X/Y/Z 按对应参考系平移，Rx/Ry/Rz 绕参考系固定轴旋转，保持当前末端位置。
- 显示单位为毫米和度；服务边界转换为米和弧度，关节目标保持度。
- 默认步长 1 mm / 1°、速度比例 5%；上限为单次 10 mm / 5°、速度 10%。
- 以上是软件输入上限，不是碰撞检测、工作空间限制或安全认证；机械臂自身仍需正确配置关节限制和安全区域。
- 不提供“按住连续运动”，不使用重复提交目标模拟连续点动。

## 状态与控制权

`ManualControlService.teaching` 持有整个 `robot-system` 的资源租约，与工作流、
遥操作、轨迹录制及其他手动操作互斥。停止失败或运动调用尚未返回时保留租约、
禁用后续移动，并提示重试停止，不能把控制权提前让给下一个操作。

状态采集、运动命令和停止分别在后台执行，Qt 主线程只处理界面。
状态按约 200 ms 调度，不堆积读取请求。超过 2 秒未刷新会明确标记并禁止新的移动；
运动调用超过 15 秒请求停止。SDK 自身阻塞可能延迟停止返回，这不是硬件看门狗。
目前适配器共享命令/读取锁时，运动期间状态可能暂缓刷新，界面不保证硬实时反馈。

软件停止调用设备的快速停止能力，不能替代实体急停。首次使用必须清空运动区域，
低速验证坐标方向和步长；不能通过画面或数值推断路径无碰撞。

## 实现位置

- `src/application/teaching.py`：资源所有权、步长校验、目标计算、停止及租约释放。
- `src/gui/controllers/teaching.py`：后台工作调度、状态有效期、保存动作和退出生命周期。
- `src/gui/views/teaching.py`：示教操作、实测数值及三维占位。
- `WorkbenchPage.full_workspace`：完整工作区与既有侧栏页面共存，不重建流程编辑器。

轨迹录制仍使用原有设备控制入口；需先退出手动示教，再开始录制，不能同时启用。
